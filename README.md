# 🚀 Гра «Ухилення від блоків» (Block Dodge) на Arduino та NeoPixel

Проста аркадна гра на виживання, реалізована на платформі Arduino з використанням адресованої світлодіодної матриці 8x8 (WS2812B) та двоосьового джойстика.

---

## 🎮 Суть гри

Ви керуєте космічним кораблем (1 піксель на найнижчому рядку матриці), який може переміщатися тільки ліворуч і праворуч. Зверху вниз із різною швидкістю падають перешкоди (астероїди чи блоки). Мета — уникати зіткнень і протриматися якнайдовше.

---

## 🛠 Компоненти та обладнання

| Компонент | Кількість | Примітка |
| :--- | :---: | :--- |
| **Arduino** (Uno / Nano / Pro Mini) | 1 шт. | Будь-яка сумісна мікроконтролерна плата |
| **LED-матриця WS2812B** | 1 шт. | Матриця 8x8 (64 адресовані світлодіоди) |

| **З'єднувальні дроти** | — | Дроти типу «мама-папа» / «мама-мама» |
| **Джерело живлення** | 5V | USB-кабель або зовнішній блок живлення |

---

## 🔌 Схема підключення

### 1. LED-матриця WS2812B
* **DIN (Data In)** $\rightarrow$ Digital Pin **7**
* **5V / VCC** $\rightarrow$ **5V** на Arduino *(або окреме джерело 5V)*
* **GND** $\rightarrow$ **GND** на Arduino

### 2. Аналоговий джойстик
* **VRx (Вісь X)** $\rightarrow$ Analog Pin **A3**
* **VCC** $\rightarrow$ **5V**
* **GND** $\rightarrow$ **GND**
*(Вісь VRy та кнопка SW не використовуються в цій грі)*

---

## 🕹 Особливості реалізації

1. **Керування:** Нахил джойстика вліво або вправо зміщує позицію гравця в межах рядка $y = 7$.
2. **Генерація блоків:** Блоки з'являються у верхньому рядку ($y = 0$) у випадкових позиціях і рухаються вниз.
3. **Прискорення:** З часом швидкість падіння блоків збільшується для ускладнення гри.
4. **Game Over:** Зіткнення гравця з будь-яким блоком зупиняє гру, а матриця спалахує червоним кольором.
